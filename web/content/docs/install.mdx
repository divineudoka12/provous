## Status

The installer and supported operating systems have not been confirmed for this frontend. We will publish a copyable install command only after it has been tested on a clean machine.

## What the install guide will cover

- Supported versions of Linux, macOS, and Windows, once confirmed.
- A verified installation method and any prerequisites.
- How to check the installed version and verify the build.
- Where local wallet and configuration data are stored.

## In the meantime

Continue with the [project introduction](/docs) or review the [privacy scope](/docs/privacy). No command shown on this page should be treated as an installer.
