## Waiting for the tool contract

Command names and output need to come from the working CLI, ideally from its own help text. No command is listed here until it has been confirmed, so examples cannot drift from the tool or imply functionality that does not exist.

## What each entry will include

- Purpose and syntax.
- Required and optional arguments.
- A copyable example using test data.
- Output captured from the current tool version.
- Any wallet, network, or privacy considerations.

For the planned first-use path, see [Quickstart](/docs/quickstart).
