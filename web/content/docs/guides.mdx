## Guide status

Guides will follow the capabilities that are present in the CLI. The first planned walkthrough is connecting an agent to a testnet payment flow. It will be written with the working tool and an example agent, not with invented interfaces.

## Planned topics

- Give an agent access to a wallet without sharing recovery secrets.
- Set and review spending boundaries, if supported by the release.
- Request a private payment from an agent.
- Inspect what the operator can see.

Each guide will state its tool version, network, prerequisites, and the behavior it actually demonstrates. See [the command reference](/docs/commands) for the source of truth for CLI syntax.
