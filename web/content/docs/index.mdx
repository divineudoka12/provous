Provous is a privacy wallet designed for AI agents to make payments on Zcash without publishing who they paid, how much, or why.

It is a developer tool intended to be used from the terminal. There is no wallet dashboard in this frontend: the site explains the project and will document the real command line as it becomes available.

## Why build this?

Agents are beginning to pay for data, APIs, and other services. When each payment is public, a transaction history can reveal what an agent is doing and who it depends on. That information may also reveal something about the person or organization behind it.

Provous explores whether shielded Zcash payments can give autonomous software a more private way to transact.

## What is ready to document?

The project direction and intended audience are clear. Exact installation steps, command names, sample output, and the tool's privacy guarantees must be checked against the working CLI before they are published as instructions.

> This documentation is an explanatory frontend, not a claim that a payment flow has been verified. The implementation notes are labeled while the tool contract is being finalized.
