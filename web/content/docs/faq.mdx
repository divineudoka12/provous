## What is Provous?

Provous is a privacy wallet designed for AI agents to make payments using Zcash shielded technology.

## Is there a dashboard?

No dashboard is part of this frontend. The project is a developer tool intended to be used from the terminal.

## Can I install it now?

The supported installation method is still being confirmed. The [installation page](/docs/install) will be updated after the command has been tested on a clean machine.

## Does this page prove that Provous payments are private?

No. The pages describe the intended privacy goal. The actual guarantees depend on the implementation and need to be checked against its threat model and behavior.

## Are the commands on this site real?

The current docs do not publish CLI commands because the working command contract has not been provided to the frontend yet. The [command reference](/docs/commands) will list the actual syntax and output once confirmed.

## Does the site track visitors?

No analytics or tracking scripts are included in this project.
