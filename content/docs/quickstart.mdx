## Status

The quickstart structure is planned, but the wallet and payment commands are waiting on a working testnet build. This page does not include simulated terminal output or made-up commands.

## Planned path

1. Install the CLI using the verified method for your operating system.
2. Create or configure a testnet wallet using a test wallet only.
3. Set the agent's payment boundaries, if supported by the release.
4. Make a small testnet payment and confirm the result using the CLI.

## Safety

Never paste a seed phrase, private key, or real wallet address into documentation examples or recordings. The published walkthrough will use test wallets and will be recorded from the actual tool.

See [Installation](/docs/install) for status, or read [the privacy page](/docs/privacy) before relying on any privacy property.
